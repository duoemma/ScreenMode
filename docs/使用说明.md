# 屏效助手 使用说明

一个常驻托盘的小工具：**按你正在用的软件，自动切换显示器情景模式**。

比如打开 Word 自动变阅读模式，打开 PUBG 自动变 FPS 模式，看视频自动变电影模式，
离开电脑 10 分钟自动变节能模式。

它有两套互相独立的切换方式，按每台显示器的实际情况自动挑：

| 通道 | 怎么生效 | 适合什么屏 |
| --- | --- | --- |
| **DDC/CI 真值** | 让显示器自己换 OSD 预设，连背光都跟着变 | 支持 DDC/CI、且在能力串里报了情景模式码的屏 |
| **画面补偿** | 改显卡的查找表（色温/对比/亮度/Gamma/饱和） | **所有屏**。尤其是读不到情景模式、或 DDC 写不进去的那种 |

写得进就用真值，写不进就自动降级用补偿，一台屏一台屏单独判断。

---

## 零、装之前先跑「屏幕体检」

双击 **`屏幕体检.exe`**（不用装、不用管理员、不读主程序配置），它会逐台告诉你：

- 这台屏能不能被软件读（DDC/CI 通不通、能读哪些码）
- 情景模式码（0xDC）**写不写得进去**（写回当前值 + 读回比对，画面不会变）
- 是不是处在高级颜色模式（HDR / 自动管理颜色），会不会挡掉补偿
- 最后点「测试画面通道」让屏上真的偏暖变亮一下，问你**「看到了吗」** ——
  这一步只能靠你的眼睛，因为 gamma 改的是显示器收到的查找表，截图看不出变化

结论三档：**可以用（自带档位）** / **可以用（画面补偿）** / **用不了**。

觉得能用，再回去装主程序；觉得不行，就别装了，省事。
「保存报告」会在桌面存一张 `屏幕体检报告-<时间>.png`，有问题直接发图。

装完主程序后它**不会被删**，一直在程序目录里（和 `屏效助手.exe` 放一起）。
以后换了新屏、或者某台突然不跟着变了，直接去那个目录双击复检就行。

> 体检全程只读。唯一的写操作是"把 0xDC 的当前值原样写回去"，等于什么都没改；
> 0x14 / 0xCC 这类码**连试都不试** —— 实测写它们会真的改掉你的色彩预设。

---

## 一、运行

**没有安装步骤。双击 `屏效助手.exe` 就运行。**

把它放在任意文件夹都行（桌面、D 盘某个目录、U 盘都行）。配置、日志、补偿基线
全部写在 exe 旁边那一个文件夹里，所以：

- **想换位置**：整个文件夹一起挪，别把 exe 单独拎出来
- **不想要了**：退出程序，把文件夹删掉

> 第一次运行如果杀软/系统拦一下，允许即可（程序只读写自己旁边的文件，
> 另外只在你手动开「开机自动启动」时才写一条注册表 Run 项）。

`屏幕体检.exe` 和主程序放一起即可，它不读主程序的配置，可以单独拷给别人先用。

## 二、第一次设置（3 步）

### 第 1 步：确认每个模式的切换通道（重要，每台显示器不一样）

打开「显示器与模式」页，列表里的 **「切换通道」** 列写的就是这个模式落到显示器的方式。

**有 DDC 的屏（走真值）**

1. 先用显示器**实体按键**切到「阅读模式」
2. 回到程序，在列表里选中「阅读模式」，点 **用当前值更正**
3. 其余模式（电影 / 节能 / FPS / 用户）同样操作一遍

**没有 DDC 的屏（走画面补偿）**

不用按键，直接给模式填补偿参数就行：选中模式 → **编辑** → 下半部分那 5 个输入框：

| 参数 | 填什么 | 例子 |
| --- | --- | --- |
| 色温 | >1 偏暖，<1 偏冷 | 阅读模式填 `1.10` |
| 对比度 | >1 更硬，<1 更柔 | 阅读模式填 `0.92` |
| 亮度 | 整体明暗（不是背光） | 节能模式填 `0.82` |
| Gamma | >1 中间调变暗 | 节能模式填 `1.25` |
| 饱和度 | >1 更艳 | FPS 模式填 `1.15` |

**1 表示不改变**，留空也等于 1。填好点确定，回主页点一下就能看到效果，不满意再改。

> 一个模式可以**同时**配档位和补偿：主屏走档位、副屏走补偿，一次切换两台一起变。
> 只配补偿不配档位也行 —— 「显示值」留空即可。

**接了多台显示器的话**，页面顶部会把每一台都列出来（带勾选框），
**只有勾选的屏才跟着场景变；没勾的屏完全不动**（不写显示器，也不套画面补偿）。
每一台的名称后面会标出它的状态：

| 标记 | 意思 | 该做什么 |
| --- | --- | --- |
| **（待配置）** | 这台屏还没识别过 | 点右上角 **引导配置** 走一遍（约 1 分钟），或者直接跳过靠补偿 |
| （什么都没标） | 已识别，走标准 `0xDC` 通道 | 不用管 |
| **（0xCC 显示应用）** 之类 | 已识别，情景模式挂在厂商私有码上 | 不用管，程序会写那个码 |
| **（亮度/对比度）** | 识别过，但这台屏的模式不走 DDC | 现在还会**自动叠一层画面补偿**，不用额外操作 |
| **（DDC 不通）** | 数据通道没通 | 查显示器菜单里的 DDC/CI 开关；补偿通道仍然可用 |

#### 不想勾死？用「跟随活跃屏」

两块屏都在用的时候，勾选就有点僵：勾了副屏，可你现在明明在主屏写文档。

把这张卡片右上角的 **跟随活跃屏** 勾上，控制目标就变成
**你此刻正在操作的那一块**：

- 在哪块屏上开 Word，哪块屏进阅读模式
- 换到另一块屏干活，大约 3 秒后控制目标跟过去，当前模式一起补上
- **原来那块屏保持上一次的样子** —— 不撤销、不恢复，不会"我一走它就弹回原样"

怎么判断"你在哪块屏"：

1. 先看**前台窗口落在哪块屏**（Word、游戏、浏览器都算）
2. 只有前台是桌面 / 任务栏 / 开始菜单 / Alt+Tab 界面时，才退回看**鼠标在哪块屏**
3. 刚插上、还没重新检测的陌生屏：不动，等程序认出来

为什么要等 3 秒：鼠标划到另一块屏取个东西，立刻转移就要重切一次档位，
有的屏切档位时画面会黑一下。所以候选屏要**连续稳定 3 秒**才真的转移，
中途抖回来一次就重新计时。这个秒数可以在 `config.json` 的
`monitors.follow_stable_seconds` 里改（1~30）。

跟随模式下勾选框会变灰 —— 因为这时候"控哪台"由活跃屏决定，勾选不再起作用；
但勾选状态会跟着活跃屏跳，你能一眼看出现在跟的是哪台。
状态卡上会写 `显示器 2 · H24T09P · 跟随中（前台窗口）`。

> 想固定控某几台，就把这个勾去掉，回到按勾选控制。

### 怎么知道切换到底有没有生效

「运行状态」页的当前模式卡片上，有一行小字写着**每台屏走了哪条路**，比如：

```
1号 0xDC 情景模式 · 2号 补偿
```

- **1号 0xDC 情景模式** —— 写进显示器自己的预设了，真·换档
- **2号 补偿** —— DDC 不通/写不进，改用画面补偿了
- **2号 亮/对+补偿** —— 只写进了亮度和对比度，再叠一层补偿
- **2号 高级颜色阻止** —— 这台屏处在高级颜色模式（HDR 或「自动管理颜色」），补偿不生效（见下面的 Q&A）
- **2号 无通道** —— 这个模式没给这台屏配任何可用的东西
- 整行变**红色** —— 这次切换一台都没成功

有了这一行，点完就知道结果，不用去翻日志。

### 新接一台显示器怎么配（引导配置）

点「显示器与模式」页右上角的 **引导配置**（第一次接上新屏时程序也会主动问你）：

1. **选显示器** → 「开始识别」
2. **用显示器按键把情景模式切到一档**（比如【标准】）→ 点「已切好，读取」
3. **再切到另一个不同的档位**（比如【电影】）→ 点「已切好，读取」
   → 程序对比两次读数，**哪个码变了，哪个就是这台屏的情景模式通道**
4. **逐个记录每个模式**：按键切到该模式 → 点「记录当前档位」
5. 点「完成」

全过程**只读不写**，不会改你任何设置。为什么必须你手动切：每台屏用的码不一样，
而且没有任何软件能替你按显示器上的实体键。

如果第二步切完发现所有读数都没变，向导会直接给你「**用画面补偿（推荐）**」这个按钮，
点一下就配好了，什么都不用再填。通常是显示器菜单里 DDC/CI 没打开，或者中间隔了扩展坞。

**引导不是必选项。** 跳过它也能用：直接给模式配画面补偿参数，「显示器与模式」页也能正常工作。

不想让某台跟着变，把它前面的勾去掉就行；一台都不勾 = 全部控制。

### 第 2 步：整理场景分组

打开「场景分组」页：

- 左边是分组（办公阅读类 / FPS 游戏类 / 影视类 …），右边是这个分组里的应用
- **从预设添加**：内置了 57 个常用软件，勾选即加（Word、WPS、Acrobat、PUBG、CS2、CF、无畏契约、腾讯视频、爱奇艺、优酷、B站、PotPlayer…）
- **手动添加**：填「显示名 + 进程名」，进程名可以点「从运行中的程序选择」直接挑
- 每个分组右上角可以改「对应模式」，改完点 **保存分组**
- 想新建分组点左边的「新建」，可以选模板（会自动带上该类的常用软件）

> 只有列表里的程序才会触发切换；不在列表里的软件不会动你的显示器。

### 第 3 步：选个舒服的确认方式

「高级设置」页：

- **切换前弹窗让我确认**：默认开。（弹窗里可以改选别的模式，倒计时结束自动按当前选择切；Esc 或「保持不变」就不切）
  如果你嫌烦，把这个勾去掉，就是检测到就悄悄切。
  弹窗选完之后是在**后台直接切换**的，不会把主界面顶到前面来。
  **每个分组只问一次**：你确认过的选择会被记住，之后离开再回来（比如打完一局退出、
  又开一局）就直接静默切回去，不会再弹。改过配置、或者你手动切过模式，才会重新问一次。
- **空闲节能**：多少分钟没操作就切节能模式，一动立刻恢复
- **默认回退**：不在任何分组的程序（比如回到桌面、开浏览器）时切回哪个模式
- **开机自动启动**：勾上就不用每次手动开

改完点右下角 **保存设置**。

最后点左下角「隐藏到托盘」，让它待在任务栏右下角就行。

### 关于「自动识别模式」

「运行状态」页**右上角**有个按钮：

| 按钮显示 | 意思 | 点一下会怎样 |
| --- | --- | --- |
| ● 自动识别中 | 正在跟着前台程序自动切 | —— |
| 手动模式 · 恢复 | 你刚手动切过，暂时不自动切 | 立刻回到自动识别 |
| 恢复自动识别 | 被暂停了 10 分钟 | 立刻取消暂停 |

在「快捷切换」里点了某个模式，就进入**手动模式**：
程序记下你当时正在用的那个程序，**只要它还没关，就不动你的显示器**；
**它一关掉，自动识别会自己同步开启**，接着打开别的软件就能无缝识别了。
不想等它关也可以直接点右上角那个按钮。

打开屏效助手自己的窗口不会影响模式 —— 它不算"前台应用"，
窗口开着的时候会保持你刚才那个程序的模式。

手动模式只在本次运行有效：**关掉程序再打开，一定是自动识别模式**，不会一直卡在手动状态。
另外如果你是在桌面上（前景是资源管理器这类常驻进程）点的快捷切换，就不会进入手动模式，
而是改成「暂停 10 分钟」—— 免得"等它关闭"永远等不到。

## 三、托盘图标

图标在**任务栏右下角**，如果没看到就点一下 `^`（隐藏图标区），把它拖到常显区。

图标颜色会跟着当前模式变：

| 图标颜色 | 含义 |
| --- | --- |
| 蓝 | 阅读模式 |
| 紫 | 电影模式 |
| 绿 | 节能模式 |
| 红 | FPS 模式 |
| 灰 | 用户模式 / 未知 |

右键图标可以：

- **立刻切换**到某个模式（会进入手动模式，当前程序关掉后自动恢复识别）
- 打开主界面
- **切回自动识别模式**（手动模式下才有得点）
- 暂停 / 恢复自动切换 10 分钟
- 开关「切换前询问我」、「开机自启」
- 退出

## 四、常见问题

**Q：打开了 Word，但没切模式？**
1. 「场景分组」里确认 winword.exe 在这个分组里（列表里能看到 Word）
2. 「显示器与模式」里确认「阅读模式」的显示值不是空
3. 看「运行状态」页的「前台程序」是不是 winword.exe（Word 的启动画面阶段进程名可能不同）
4. 看「最近事件」或程序目录下的 `app.log`

**Q：完全不切换，日志说找不到显示器？**
显示器菜单里要把 **DDC/CI** 打开（有的叫「显示器控制」「DDC/CI 控制」）。
笔记本内屏基本不支持；部分扩展坞、KVM 会中转掉 DDC 信号，尽量显示器直连 HDMI / DP。

**Q：我自己按显示器按键改了模式，程序马上又改回去了？**
程序会检测这种情况并暂停自动切换 10 分钟——但如果只改了一次，可能需要等它确认（连续两次读数不一致）。
托盘里也能手动「暂停自动切换 10 分钟」。

**Q：弹窗老是跳出来烦人？**
「高级设置」里取消「切换前弹窗让我确认」，或者点托盘菜单里的这一项。

**Q：看视频的时候屏幕被切成节能模式了？**
这是因为「空闲节能」看的是"多久没碰键盘鼠标"，而看片时本来就不碰。
新版已经处理：**只要有声音在放、或者前台是全屏窗口，就不算空闲**，
在「高级设置」页第一行右边能看到两个开关（默认都开着）：

- 「看视频/听歌时不算空闲」——读系统默认播放设备的音量峰值，浏览器、本地播放器、
  音乐软件都管用；判断的是"最近 90 秒内有没有响过"，所以对白停顿不会误判。
- 「全屏播放时不算空闲」——静音看全屏视频也认。

如果已经在节能模式里，开始放视频后会自动切回原来的模式。
唯一识别不了的是**静音 + 窗口化**的视频，动一下鼠标就恢复了。

**Q：打游戏时每隔几秒卡一下，像跳了个弹窗？**
这是 v2.0 起已修掉的问题，先升级到最新版（当前 2.5.0）。原因不是游戏本身，而是**程序在反复切你的显示器模式**：
全屏游戏运行时前台窗口会周期性地跳到别的进程上（读图加载、Steam 覆盖层、系统弹窗），
旧版那一瞬间就判定"你离开了游戏"→ 切回默认模式，下一轮又切回 FPS 模式。
显示器每切换一次情景模式，画面就会断一下，体感就是掉帧。

新版的处理：认出这是「全屏程序还在跑」，**90 秒内一次都不切**；同时把读显示器的频率
从每 1.5 秒降到每 15 秒（读一次要 60ms，本身也会丢帧）。
如果升级后还卡，看 `app.log` 里有没有 `前台离开「…」（现在是 xxx.exe）`，
那条会告诉你到底是哪个进程在抢前台。

**Q：打游戏的时候每次退出对局都要重新点弹窗？**
不用了。现在按「每个分组只问一次」处理：第一次进这个分组弹一次，之后记住你的选择，
再来就静默切回去。另外程序会把同一款游戏的多个进程（`TslGame.exe` / `TslGame_BE.exe`
之类）当成同一个应用，游戏换进程也不会重新问。

**Q：我手动切了模式，程序怎么不管我了？**
这是有意的：手动切完会进入「手动模式」，直到你正在用的那个程序关掉为止。
想马上恢复，点「运行状态」右上角的「手动模式 · 恢复」，或者托盘菜单里的「切回自动识别模式」。

**Q：副屏菜单里明明有「情景模式」，程序却说识别不到 / 叫我去引导？**
因为「菜单里有」和「DDC 里报得出来」是两件事。不少屏（尤其用桥接芯片的）
把情景模式挂在厂商私有码上，甚至在 MCCS 能力串里压根不报 `0xDC` —— 硬猜是猜不出来的。

点「显示器与模式」页右上角的 **引导配置**，按提示用按键切两个不同的档位，
程序对比前后读数就能找出真正的那个码。全程只读，不会改你的设置。

**Q：引导跑完说「没有暴露情景模式通道」怎么办？**
意思是切了两次，所有码的读数都没变。常见原因：
显示器菜单里 DDC/CI 关着（有的叫「显示器控制」）、中间隔了扩展坞 / KVM、
或者这台屏的模式切换根本不走 DDC。

**不影响使用。** 直接跳导向导，在「显示器与模式」里给模式填**画面补偿**参数即可 ——
色温、对比度、亮度、Gamma、饱和度都是改显卡查找表，不依赖 DDC，切一下就生效。

**Q：画面补偿到底是什么？它和显示器的"亮度"有什么不一样？**
画面补偿改的是**显卡的 256×3 查找表（Gamma Ramp）** —— 像素值在送去显示器之前就被改掉了。
所以它不需要显示器配合，任何显卡、任何显示器都成立。

它和显示器自己的菜单项的区别：

| | 画面补偿能做的 | 只有显示器能做的 |
| --- | --- | --- |
| 色温 / 色调 | ✅ 提红压蓝 | —— |
| 对比度 | ✅ 绕中灰缩放 | 显示器那边的动态对比 |
| 亮度 | ✅ 像素级整体增益 | ❌ **背光亮度改不了** |
| 中间调层次 | ✅ Gamma 曲线 | —— |
| 饱和度 | ✅ 绕灰轴展开 | —— |
| 锐度 / 降噪 | ❌ | ✅ |

**Q：副屏看着是变了，但感觉没有主屏变得"狠"？**
正常。主屏走的是 DDC 真值，是显示器整套预设一起换（连背光、动态对比、锐度都变了）；
副屏走的是画面补偿，只能改像素值，背光不会动。想要更明显的差别，把补偿参数调大一点
（比如色温 1.20、对比度 1.15），或者干脆手动把副屏的背光调低一档再配模式。

**Q：切完模式，隔一段时间屏幕又变回去了？**
有几种可能：① 程序判定你离开了那个分组，按「默认回退」切回去了；
② 空闲节能到时间了；③ 你用显示器按键自己改过，程序以为你要手动接管。
看「最近事件」那几条日志就能分清是哪一种。

**Q：我明明没开 HDR，为什么程序说我开了？**

因为这一位根本不是"HDR"专用位。Windows 把 **HDR** 和 **「自动管理颜色」**
（Windows 11 的颜色管理功能，开起来是 10bit + 广色域）放在同一个状态位上，
系统层根本分不出来是哪个 —— 程序也一样。

所以 2.3.0 起统一叫 **「高级颜色」**，而且**只在那台屏真的要靠画面补偿时才提醒**：
走显示器自带档位的屏，开没开 HDR 都跟补偿无关，提都不提。

想确认到底是什么：`设置 → 系统 → 显示 → 高级显示`，
那里 HDR 和「自动管理颜色」是两个独立开关。

**Q：开着 HDR（或自动管理颜色）的时候为什么没效果？**
一开，Windows 会切到高级颜色管线，**驱动接管 gamma 查找表** ——
程序写进去会返回成功，但画面一个像素都不会变。这是系统限制，不是 bug。

程序检测到会提醒你一次（每块屏 10 分钟最多一次），但**不会替你去关** ——
HDR 是你为了游戏/影片主动开的，替你关掉比不生效更糟。

想要补偿效果只有两个办法：到 `高级显示` 里关掉 HDR / 自动管理颜色，
或者这台屏改用 DDC 通道（如果它支持）。

**Q：副屏的色温变化，是根据主屏切到哪一档算出来的吗？**
不是。**补偿参数是写在"模式"上的固定值**（色温 ×1.10、对比度 ×0.92 这样），
跟主屏实际切到哪个档位没有任何关系 —— 程序不会去读主屏的值再"换算"给副屏。

所以两块屏看起来幅度可能不一样：主屏是显示器自己的原厂预设（背光、芯片处理都参与），
副屏是显卡端模拟出来的（只能改像素值，改不了背光）。觉得副屏太淡或太重，
就到「显示器与模式」→ 编辑那个模式 → 调「画面补偿」那 5 个参数。

**Q：补偿的效果关掉程序就没了？**
不会，**关程序后仍然保留** —— 切到电影模式后关程序，画面应该还是电影模式，
而不是"一关就变回去"。

想撤销：**显示器与模式** → 右下角 **恢复原始画面**。
它会写回程序第一次采样到的那份原始曲线（存在程序目录的 `gamma_base.json` 里），
不是简单的"归零"，所以不会把你显卡驱动原本的色彩校正一起抹掉。

重装系统、重装显卡驱动、或者重启之后，系统自己也会把查找表重置回默认。

**Q：想让某台显示器不跟着切？**
把「显示器与模式」页顶上它前面的勾去掉就行（改完立刻生效，不用点保存）。
没勾的屏**两条通道都不碰** —— 不写 DDC，也不套画面补偿，就停在你上次手动设的样子。
取消勾选的那一刻，它上面残留的补偿也会被立刻撤掉。
一台都不勾 = 控制所有显示器（这是为了配置坏掉时程序不至于静默不干活）。

**Q：两块屏我都在用，能不能让它自己跟？**
能 —— 勾上「显示器与模式」卡片右上角的 **跟随活跃屏**（详见
[不想勾死？用「跟随活跃屏」](#不想勾死用跟随活跃屏)）。它会自己判断你在哪块屏上操作，
把情景模式落到那块屏上，旧屏保持上一次的样子。

两个细节值得先知道：
1. **鼠标划过去不会立刻切**，要连续停留 3 秒。不这样的话，你伸手去副屏点一下
   就开始切档位，有的屏切档位会黑一下，很烦。
2. **勾选框会变灰**。这时候"控哪台"由活跃屏决定，勾选不再起作用 ——
   但它的勾选状态会跟着活跃屏跳，所以依然能一眼看出现在跟的是哪台。

**Q：为什么我的副屏读不到情景模式？是不是年代太久/牌子不行？**
基本无关。`0x10` 亮度 / `0x12` 对比度是 MCCS 的基础项，2005 年后的液晶几乎都有；
但 `0xDC`（情景模式）是**厂家可选实现**的码，实现成本比色彩预设高，很多固件索性不报。
同一个品牌也可能有的型号报、有的不报（本机两块同品牌的屏，2022 年产的那块就没有）。

另外两个常见原因：显示器 OSD 里的 **DDC/CI 开关是关着的**；中间隔了**扩展坞 / KVM**。

不管是哪种，2.2.0 起都能用**画面补偿**顶上，不影响使用。

**Q：DDC / CI 到底是什么？**
**DDC** 是显卡和显示器之间的那条数据通道（复用 HDMI/DP 里的 I²C 两根线，走 EDID 交换能力清单），
**CI** 是跑在这条通道上的命令集（正式标准叫 MCCS）。合起来就是"电脑不用按实体键也能改显示器菜单"。
程序写的是 VCP 码：`0xDC` = 情景模式，`0x10` = 亮度，`0x12` = 对比度。
`0x14`（色彩预设）虽然很多屏都有，但**写入不可靠**（实测写 8 读回 5），所以程序默认完全不碰它。

## 五、卸载

**退出程序，把整个文件夹删掉 —— 就这两步。** 没有卸载程序。

删之前顺手做两件事：

1. 屏幕要是正套着画面补偿，先进界面点 **「恢复原始画面」**，
   把显卡查找表还原（不点也行，重启一次系统会自动重置）。
2. 开过开机自启的话，删完到 **任务管理器 → 启动** 里把「屏效助手」关掉。

## 六、小技巧

- 一个软件想触发两种模式做不到（一个进程只能属于分组的某一条），但可以给同一软件建两个分组切换着用——一般没必要。
- 有些客户端进程名不固定（比如网页版视频），可以用「窗口标题包含」匹配：进程名留空，标题关键字填「哔哩哔哩」。
- 想加内置预设（让它在「从预设添加」里出现），改 `screenmode/presets.py` 加一行即可，详见 README。
